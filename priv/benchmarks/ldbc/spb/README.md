# Pinned SPB workload assets

These files are copied without query rewrites from LDBC Semantic Publishing
Benchmark 2.0.2 commit `ce6323c0936306729408233dc70d26f2389b34c6`.
`checksums.sha256` protects the 25 advanced standard aggregation templates,
three advanced editorial templates, and three advanced standard validation
templates. `LICENSE.upstream` and `NOTICE.upstream` preserve the upstream
Apache 2.0 licensing material.

TripleStore supplies typed substitution parameters and local execution metadata
in `TripleStore.Benchmark.LDBC.SPB.Workload`. Optional text, geospatial, context,
replication, backup, and failover actions are never included in the mandatory
query/editorial rate unless their separately declared capability is supported.
